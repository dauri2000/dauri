# dauri

## Descarga experimental IF54: movimiento e inventario Java

[Descargar el JAR modificado](https://github.com/dauri2000/dauri/raw/refs/heads/download-if54-java-movement-inventory/downloads/ViaFabricPlus-IF54-JavaMovimientoInventario-Experimental.jar)

El archivo se almacena mediante Git LFS. Usa el enlace anterior o el botón
**Download raw file** de GitHub. El ZIP automático del repositorio puede contener
solo un puntero LFS; no sirve como sustituto del JAR.

Requiere Minecraft **26.3**, Java **25+** y ViaFabricPlus compatible con la base
IF54.2 (el manifiesto indica >=5.0.2). Sustituye el mod original; no cargues ambos.

Se conservaron rutas Java para el movimiento del jugador sin montura y los
controles de inventario. Las monturas y demás componentes conservan la base
Bedrock. El servidor mantiene autoridad sobre posiciones y resultados.

**Experimental: no se probó dentro de Minecraft.** Pasaron la integridad CRC,
la revisión del bytecode, 31 comprobaciones aisladas y una reconstrucción
idéntica desde las fuentes del parche. No se garantiza ausencia de fallos.

- [Detalles y pruebas pendientes](downloads/LEEME.md)
- [Fuentes del parche](downloads/FuentesDelParche.zip) (requieren el JAR base original)
- [SHA-256 de los archivos](downloads/SHA256SUMS)
